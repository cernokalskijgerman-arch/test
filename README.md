# Glyph Studio (Nothing Phone 3a Pro / 3)

Центр управления и создания световых анимаций для смартфонов **Nothing** с интерфейсом **iOS Liquid Glass**, аутентичным точечным шрифтом **Nothing NDOT 57** и поддержкой тестирования на смартфонах через **Expo Go** и в нативном Android.

---

## 🚀 Быстрый запуск на телефоне (Expo Go)

1. Установите приложение **Expo Go** на ваш телефон (из Google Play или App Store).
2. Запустите двойным кликом файл **`start-expo.bat`** (или `start-expo-tunnel.bat`).
3. Отсканируйте появившийся QR-код камерой смартфона или через приложение Expo Go.

---

## ☁️ Выкатка бэкапов на GitHub (в 1 клик)

Для выкатки проекта и резервных копий на GitHub подготовлен скрипт **[`backup-to-github.bat`](./backup-to-github.bat)**:

1. **Создайте репозиторий на GitHub**:
   - Перейдите на [github.com/new](https://github.com/new).
   - Задайте имя (например, `glyph-studio`) и нажмите **Create repository**.
   - Скопируйте HTTPS-ссылку (например, `https://github.com/username/glyph-studio.git`).

2. **Запустите бэкап**:
   - Дважды кликните по файлу **`backup-to-github.bat`**.
   - При первом запуске вставьте ссылку на ваш репозиторий.
   - Скрипт автоматически:
     - Упакует все файлы проекта (исключая тяжелый кэш и `node_modules`).
     - Создаст коммит с меткой времени.
     - Отправит (push) все данные в ветку `main` вашего GitHub репозитория.

3. **Автоматический GitHub Actions Backup**:
   - В проект встроен workflow [`.github/workflows/backup-and-release.yml`](./.github/workflows/backup-and-release.yml).
   - При каждом пуше GitHub автоматически проверит целостность проекта, создаст упакованный ZIP-архив релиза и сохранит его во вкладке **Releases** на GitHub.

## 🌟 Возможности приложения

- **Минималистичный силуэт камеры**: блок камер Nothing Phone (3a Pro / 3) с парящим дизайном без лишнего корпуса.
- **Белые непрерывные глифы**: 3 монолитные неоновые трубки (Ice-White `#FFFFFF`) со световым ореолом и без пиксельных зазоров.
- **iOS Liquid Glass**: настоящее размытие заднего фона с эффектом матового стекла и зеркальной фаской.
- **Фирменный шрифт NDOT 57**: точечная ретро-футуристическая типографика Nothing OS.
- **Степ-секвенсор**: 16-тактовая сетка дорожек с регулировкой BPM.
- **FFT Эквалайзер**: частотное разделение звука на верхнюю, нижнюю и правую дуги.
- **Аркады**: «Световая бутылочка» с замедлением вращения и тест реакции.
