# Glyph Studio — Nothing Phone (3 / 3a Pro) [Expo Go]

Кроссплатформенное приложение для управления светодиодными глифами (Glyph Interface) на React Native + Expo.
Разработано для тестирования в реальном времени на мобильных телефонах через приложение **Expo Go** (iOS и Android).

---

## 🚀 Быстрый запуск на телефоне

### 1. Подготовка
1. Установите бесплатное приложение **Expo Go** на свой телефон:
   - [Google Play (Android)](https://play.google.com/store/apps/details?id=host.exp.exponent)
   - [App Store (iOS)](https://apps.apple.com/app/expo-go/id982107779)
2. Убедитесь, что телефон и компьютер подключены к одной локальной Wi-Fi сети (или используйте Tunnel-режим).

### 2. Запуск
Из папки проекта:
```bash
cd c:\Users\KAORU\Desktop\BABA\expo-glyph-studio
npm start
```
*Или просто дважды кликните `start-expo.bat` в папке `c:\Users\KAORU\Desktop\BABA`.*

### 3. Сканирование QR-кода
- **Android:** Откройте приложение Expo Go и нажмите **«Scan QR code»**, наведите камеру на QR-код в терминале.
- **iPhone / iOS:** Откройте стандартную камеру iPhone, наведите на QR-код и нажмите желтое уведомление «Open in Expo Go».

> 💡 **Совет:** Если телефон на мобильном интернете или в другой сети Wi-Fi, запустите `start-expo-tunnel.bat` (режим `npx expo start --tunnel`).

## ✨ Возможности и режимы приложения

### 1. 📱 ХАБ (Dashboard)
- Интерактивный симулятор задней панели Nothing Phone (3) с **33 дискретными светодиодами** вокруг блока камер.
- Минималистичный векторный контур камеры (чистая эстетика без лишних деталей и нагромождений):
  - Главный внешний круг.
  - Верхний органический контур с двумя линзами (одиночная и концентрическая двойная).
  - Отдельная круглая камера слева.
  - Горизонтальный модуль перископа справа со скругленным прямоугольным зрачком.
  - 3 дуги глифов: **Верх-Лево (12 LED)**, **Низ-Лево (6 LED)**, **Правая дуга (15 LED)**.
- Интерактивный тап по каждому светодиоду с тактильной отдачей (Haptic feedback).
- Кнопка быстрого включения/выключения всего света.

### 2. 🎹 Степ-секвенсор (Step Sequencer)
- 16-тактовая сетка для создания собственных световых ритмов.
- Управление BPM (60 — 220 ударов в минуту) в реальном времени.
- Встроенные пресеты: *Cyber Metro*, *Heartbeat*, *Strobe Wave*, *Orbit Spin*.
- Экспорт секвенций в формат `.glyph`.

### 3. 📊 Музыкальный эквалайзер / Визуализатор
- Симуляция 8-полосного FFT спектроанализатора звуковых частот (Sub, Bass, Low-Mid, Mid, Presence, Treble).
- 4 адаптивных режима визуализации: *Neon Pulse*, *Sub-Bass Cannon*, *Frequency Orbit*, *Voice Wave*.
- Демо-треки для тестирования реакции глифов на бас и ритм.

### 4. ⚡ Фоновые утилиты и свет
- **Глиф-таймер (10с, 30с, 60с):** Светодиоды по контуру камеры плавно гаснут по мере истечения времени с финальной вспышкой.
- **Индикатор заряда батареи:** Шкала из 33 LED визуализирует уровень аккумулятора.
- **Стробоскоп:** Высокочастотное мерцание (4 — 16 Гц) для сигналов.
- **Мягкий свет (Fill Light / Torch):** Полноценная кольцевая подсветка для съемки фото/видео.

### 5. 🎯 Глиф-аркада (Мини-игры)
- **«Световая бутылочка» (Glyph Roulette):** Световой луч быстро крутится вокруг камеры и реалистично замедляется с физической инерцией и щелчками, останавливаясь на случайном секторе.
- **«Glyph Reflex»:** Тест скорости реакции. Поймайте несущийся светодиод в подсвеченной целевой зоне, набирайте очки и комбо-стрики!
